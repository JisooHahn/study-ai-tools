# 클로드 코드 실습 파일

**👉 https://github.com/AI-Dico/claude-code-practice-files**

위키독스에서 연재 중인 책 [『코딩 배우지 마세요, 클로드 코드 하세요』](https://wikidocs.net/book/20178)의 독자용 실습 파일 모음입니다.
문서·표·영수증·계약서까지 **전부 가상으로 만든 데이터**입니다. 카드내역에 보이는 가게 이름도 실제 거래가 아니라 프로그램으로 만들어낸 가짜 내역이니, 마음 놓고 망가뜨리며 연습하세요.

---

## 내려받는 법 (왕초보용)

1. 이 페이지 오른쪽 위의 초록색 **Code ▾** 버튼을 누릅니다.
2. 맨 아래 **Download ZIP**을 누릅니다.
3. 내려받은 ZIP 파일의 압축을 풉니다. `claude-code-practice-files-master`라는 폴더가 생깁니다.
4. 폴더 이름 뒤의 `-master`는 지워서 `claude-code-practice-files`로 바꾸고(우클릭 → 이름 변경), **바탕화면**처럼 찾기 쉬운 곳에 옮겨 두세요. 아래 안내는 전부 이 이름 기준입니다.

> 참고: `git clone`이라는 방법도 있지만 몰라도 됩니다. 2장을 마친 분은 클로드 코드에게 "이 주소 받아와줘"라고 시켜도 됩니다.

## 시작하는 법 — cd와 claude, 두 줄이면 됩니다

1. **터미널을 엽니다.**
   - 맥: `Cmd + Space` → "터미널" 입력 → Enter
   - 윈도우: 시작 메뉴에서 **Ubuntu**를 찾아 여세요 (부록 A에서 설치한 WSL 창입니다 — 일반 PowerShell 창에서는 안 됩니다)
2. **실습 폴더로 이동합니다.** 예를 들어 1장이라면:
   ```
   cd 바탕화면/claude-code-practice-files/ch01-다운로드정리
   ```
   > 맥은 `cd ~/Desktop/claude-code-practice-files/ch01-다운로드정리`,
   > 윈도우(WSL)는 `cd /mnt/c/Users/내이름/Desktop/claude-code-practice-files/ch01-다운로드정리`
   > 처럼 경로가 조금 다를 수 있습니다. 폴더를 어디에 두었는지에 맞춰 주세요.
3. **클로드 코드를 켭니다.**
   ```
   claude
   ```
4. `>` 프롬프트가 보이면 출근 완료입니다.

**폴더로 이동해서 claude를 켜는 것, 이게 이미 첫 실습입니다.**

## 폴더 안내

| 폴더 | 무엇이 들어있나 | 책 어느 절에서 쓰나 |
|------|----------------|----------------|
| `ch01-다운로드정리/` | 문서·사진·PDF·압축파일이 뒤섞인 "다운로드 폴더" | 1장 — 종류별 분류 실습 |
| `ch02-시키는법/` | 회의록, 설문결과 CSV, 자료조사 메모 | 2장 — 시키는 법 연습 |
| `ch03-파일맡기기/` | 문서 30개(`자료/`), 보고서 양식, 계약서 PDF, 영수증 사진 | 3장 — 파일 읽고 정리 맡기기 |
| `ch04-숫자맡기기/` | 카드내역 6개월치 + 10월 한 달치 CSV | 4장 — 숫자 집계 맡기기 |
| `ch05-조사맡기기/` | 지난번 브리핑 샘플 | 5장 — 조사·보고 맡기기 |
| `ch06-만들기/` | 시작 안내 한 장뿐 (거의 빈 폴더가 정상입니다) | 6장 — 빈 폴더에서 만들기 |
| `ch07-반복줄이기/` | 4장을 마친 상태의 스냅샷 + 깨진 데이터 | 7장 — 반복 작업 줄이기 |
| `ch08-안전하게/` | 가짜 `.env`, 가짜 고객명단, 깨진 HTML | 8장 — 금지선과 에러 다루기 |

### ch07이 좀 특이합니다

`ch07-반복줄이기/`는 **4장을 마친 상태를 미리 만들어둔 폴더**입니다.
4장을 건너뛰었어도 7장을 바로 실습할 수 있습니다.

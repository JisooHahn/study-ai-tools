## Chapter 1. 첫 출근 — 시키고, 멈추고, 고치기

**핵심**
- Claude Code = **내 폴더에 직접 들어와** 파일을 읽고, 정리하고, 결과를 **파일로 남기는** AI → 복붙이 사라진다.
- 단순 글쓰기·번역은 웹이 낫다. "이 폴더의 / 이 문서들을"이 나오면 Claude Code 영역.
- 판단 기준: 대화·글쓰기 → **채팅**, 앱 화면에서 업무 맡기기 → **코워크**, 내 폴더의 파일·도구를 엮기 → **클로드 코드**.
- 첫 질문은 "만들어줘"가 아니라 **"뭐가 있어?"** (읽기만 시키면 아무것도 안 바뀜).
- **"아직 옮기지는 마"** — 처음 며칠은 모든 부탁 끝에 선 긋기.
- 확인창이 뜨면 아직 아무 일도 안 일어난 것. 처음엔 **이번 작업만 승인하는 Yes**.
- **Esc = 끼어들기**. 방향이 이상하면 끝까지 기다리지 말고 바로 멈추고 고친다.

**실습 프롬프트**

```bash
mkdir 실습폴더
cd 실습폴더
claude
```

```text
① 이 폴더에 뭐가 있어?
```

```text
② 여기 있는 문서들을 종류별로 분류해서 보여줘. 아직 옮기지는 마.
```

```text
③ 아까 분류한 대로 폴더를 만들어서 정리해줘.
```
→ 작업 중 **Esc** 한 번

```text
④ PDF는 빼고, 폴더 이름은 한국어로 해줘. 계속해.
```

**미션**: 다운로드 폴더에서 "뭐가 있어?" → 분류만 보기 → 정리 중 일부러 Esc → 조건 수정 후 계속.

## Chapter 2. 시키는 법 — 계획 먼저, 작게, 명확하게

**핵심**
- 기준을 안 주면 **평균(가장 흔한 답)** 이 온다. 한 마디 기준이 결과의 격을 바꾼다. (예: "Linear 스타일로", "개조식으로", "임원 보고용으로")
- **좋은 프롬프트 3요소: 대상 · 기준 · 결과물**

| 나쁜 예 | 좋은 예 |
|---|---|
| 정리해줘 | `@회의록.txt` 에서 결정사항과 할 일을 담당자별 표로 정리해줘 |
| 보고서 써줘 | 동아리 활동 결과보고서 초안을 A4 2장, 개조식으로 써줘. 대상은 지원사업 심사위원 |
| 더 좋게 만들어줘 | 이 발표자료에서 한 슬라이드에 글이 5줄 넘는 곳을 찾아 3줄 이내로 줄여줘 |

- **`@` = 파일 가리키기** (`@`만 쳐도 자동완성, 한글 파일명 OK)
- 결과물 모양을 끝맺음으로 지정: "설명해줘"(대화) / **"파일로 저장해줘"**(새 파일) / "고쳐서 덮어써줘"(원본 수정) / "표로 정리해줘"
- **캡처 넣기**: 드래그 / 캡처 후 `Ctrl+V`(맥도 Ctrl+V) / `@캡처.png`. 말로 가능한 건 말로, 말로 어려운 디테일만 캡처. 캡처 전 개인정보 3초 점검.
- **작게**: 한 문장에 여러 일 던지지 말고 "요약 먼저 → 확인 → 다음".

### 작업 루틴 4칸

```
① 계획 먼저 (Plan Mode) → ② 작게 실행 → ③ 확인 → ④ 멈추고 수정 (Esc)
```

### 권한 모드 4가지 (`Shift+Tab`으로 순환: auto → manual → accept edits → plan)

| 모드 | 화면 표시 | 동작 | 언제 |
|---|---|---|---|
| auto | `⏵⏵ auto mode on` | AI가 확인창을 대신 심사 | 충분히 익숙해진 뒤 긴 작업 |
| **manual** | `⏸ manual mode on` | 허용 안 된 변경·명령 전에 확인 | **처음, 중요한 작업 (책의 출발점)** |
| accept edits | `⏵⏵ accept edits on` | 작업 폴더 안 편집·생성·이동·삭제 자동 허용 | 반복 작업 빠르게 |
| plan | `⏸ plan mode on` | 조사·계획만, 승인 전엔 파일 안 고침 | 큰 작업 전 |

> ⚠️ `--dangerously-skip-permissions`는 초보 단계에서 금지. 비밀번호·계정 정보는 대화창에 직접 입력 금지.

**계획 검토 3가지**: 의도한 범위만? 단계가 너무 크지 않나? 빠진 파일은?
**승인 시**: `Yes, manually approve edits` 선택 → `⏸ manual mode on` 확인 후 실행.

### 실습 프롬프트

```text
# Plan Mode(⏸ plan mode on)에서
① 이 폴더의 파일들을 종류별 폴더로 정리하려고 해. 계획을 단계별로 세워줘.
```

```text
2단계는 빼고 다시 계획해줘.
```

```text
# 계획보다 질문 먼저 받기(인터뷰)
이 폴더를 정리하기 전에, 일을 제대로 하려면 나한테 확인할 것부터 질문해줘. 한 번에 하나씩 묻고, 다 물어본 다음에 계획을 세워줘.
```

```text
# 인터뷰를 스킬로 저장 (manual 모드에서) → 다음부터 /interview
이 질문 절차를 .claude/skills/interview/SKILL.md에 스킬로 저장해줘
# 모든 폴더에서 쓰려면 위치를 ~/.claude/skills/interview/SKILL.md 로
```

### 되돌리기 (체크포인트)

- 입력칸이 빈 상태에서 **`Esc` 두 번** 또는 `/rewind` → 돌아갈 지시 선택 → `Restore code and conversation` / `Restore code` / `Restore conversation`
- 말로: "방금 한 것 취소해줘"
- ⚠️ 체크포인트는 **AI가 편집한 내용만** 되돌림. 명령(mv·rm)으로 옮기거나 지운 파일, 내가 직접 만진 파일은 복구 안 됨 → 큰 작업 전엔 **복사본 백업**.

### 타임머신(git) — 배우지 말고 시키기

```text
② 이 폴더 버전 관리 시작해줘. 그리고 지금 상태를 저장해줘.
```

| 상황 | 말 |
|---|---|
| 큰 작업 전 | 지금 상태 저장해줘 |
| 잘못됐을 때 | 마지막으로 저장한 상태로 돌려줘 |
| 변경 확인 | 저장한 뒤로 뭐가 바뀌었어? |

**미션**: 같은 파일로 "정리해줘" vs "`@파일` 을 [기준] 으로 [결과물] 만들어줘" 비교 → `/clear` 사이에. 보너스: `@복사본.txt 첫 줄을 다른 문장으로 바꿔줘` → Esc 두 번 → Restore code.

## Chapter 3. 파일 맡기기

**핵심**
- 공식: **무더기를 `@`로 가리키고, 결과를 파일로 받는다.** 복붙 0회.
- 모든 실습은 2장 루틴 그대로 (계획 → 1단계만 → 확인 → 다음).
- 수십 개가 넘으면 **10개씩 끊어서** 중간 결과 확인.
- 밖으로 나가는 글(메일·공지·제출물)은 **초안까지만**. 발송은 사람이.
- PDF·사진·스캔도 읽음. 돈·날짜·이름은 **원본과 대조**.
- 대화(메모지)가 꽉 차면 오래된 내용부터 밀려남.

| 상황 | 처방 |
|---|---|
| 길어졌지만 같은 작업 | `/compact` (요약하고 이어가기) |
| 완전히 다른 일 | `/clear` |
| 다음 날 이어서 | 터미널에서 `claude --continue` |

**실습 프롬프트**

```text
① 이 폴더를 정리하고 싶어. 파일들을 종류별로 분류해서 어떤 폴더 구조로 정리할지 계획만 보여줘. 아직 옮기지는 마.
```

```text
② 좋아. 1단계만 실행해줘. 나머지는 기다려.
```

## Chapter 4. 숫자 맡기기

**핵심**
- CSV·엑셀 등 **표 모양 파일은 전부 AI 직원의 밥**. 함수는 AI가 쓰고 나는 질문만.
- 분석 전에 먼저 구경: **"이 데이터에서 뭐가 보여?"**
- AI는 뒤에서 **코드(파이썬)를 실행해 실제로 계산**한다 → 확인창의 코드는 "계산기 두드리는 소리".
- 산출물은 **차트 포함 보고서 파일**로. CSV를 엑셀에서 열 거면 "한글이 안 깨지게".
- **검증 3가지**: ① 원본은 안 바뀜(나란히 대조) ② **수식이 살아 있는 엑셀**로 받기 ③ 검산도 시키기.
- 숫자 일은 반복 → 다음 달엔 "지난달과 같은 방식으로" (7장에서 영구 규칙화).
- 실습 파일: `github.com/AI-Dico/claude-code-practice-files` → `ch04-숫자맡기기`

**실습 프롬프트**

```text
① @카드내역.csv 읽고 이 데이터에서 뭐가 보이는지 말해줘. 어떤 항목들이 있고, 기간은 언제부터 언제까지인지도.
```

```text
# 이어서 자유롭게
월별 지출 추이가 어때?
제일 많이 쓴 곳 5군데는?
주말과 평일 씀씀이가 달라?
이상하게 튀는 값 있어?
```

```text
② @카드내역.csv 분석해서 핵심 지표 3개를 뽑고, 월별 추이 표와 함께 "지출분석.md" 보고서로 저장해줘. 맨 위에 3줄 요약부터.
```


```text

⑤ 이 분석을 엑셀 파일로도 저장해줘. 시트는 ①원본 그대로 ②정리한 데이터 ③월별 집계 순서로 나누고, 합계와 평균은 값으로 박지 말고 SUM, AVERAGE 수식으로 살려서.
```

## Chapter 5. 조사 맡기기

**핵심**
- 조사의 안전벨트: 항상 **"웹에서 검색해서" + "출처 달아서"**. 출처 없는 주장은 없는 셈 친다.
- AI는 아는 척을 할 때가 있다(숫자·연도·이름 특히 위험). 중요한 숫자는 **출처를 직접 클릭**.
- AI의 기본 지식은 인쇄된 책 → "요즘·최신·올해"는 반드시 검색.
- 비교는 **기준을 먼저** 정해주고 표로 받는다 ("뭘 비교할지 정하는 게 상사의 일").
- 맡기는 3단계: **조사 → 초안 → 내 톤** (+ 발표가 잡히면 슬라이드까지).
- 비교 대상이 많으면 AI가 알아서 **서브에이전트**로 일을 나눔.

**실습 프롬프트**

```text
① 2026년 기준 많이 쓰는 협업 도구를 웹에서 검색해서 정리해줘. 각 내용마다 출처 링크를 달아줘.
```

```text
② 노션, 슬랙, 잔디를 웹에서 조사해서 비교표로 만들어줘. 기준은 ①월 요금(1인당) ②무료 한도 ③한국어 지원 ④우리 같은 10인 모임에 맞는지. 각 칸에 출처 달고, 마지막 줄에 추천과 이유 한 줄. "협업툴비교.md"로 저장해줘.
```

```text
# 경쟁사 분석 응용
경쟁사 A, B, C의 가격 정책과 최근 6개월 보도자료를 조사해서 기준별 비교표 + 시사점 3개로 정리해줘
```

```text
③ @협업툴비교.md 를 바탕으로 팀장님께 보고할 1쪽 브리핑을 써줘. 구성은 결론 먼저 → 근거 3개 → 예상 질문과 답 2개. "브리핑_협업툴.md"로 저장해줘.
```

```text
④ @브리핑_협업툴.md 를 @지난번브리핑.md 의 말투와 형식에 맞춰 고쳐줘.
```

```text
⑤ @브리핑_협업툴.md 를 바탕으로 발표 슬라이드 5장을 만들어줘. 구성은 표지 → 결론 한 장 → 비교표 → 근거 차트 → 다음 단계. 글자는 멀리서도 보이게 크게, 한 장에 메시지는 하나씩. "협업툴_발표.html"로 저장하고, 브라우저에서 열어 ← → 키로 넘길 수 있게 해줘.
```
→ `F11`(맥 `Ctrl+Cmd+F`)로 전체 화면 발표. 파워포인트 파일이 필요하면 "같은 내용을 파워포인트 파일로도 만들어줘".

## Chapter 6. 생각을 진짜로 만들기 — 코딩 없이

## Chapter 7. 반복 줄이기 — CLAUDE.md

**핵심**
- **CLAUDE.md** = AI가 켜질 때마다 **자동으로 먼저 읽는 온보딩 문서**(장기 기억). 대화(메모지)는 밀려나도 이건 매번 다시 읽힌다.
- 위치 두 곳 (함께 읽힘 → 서로 모순되지 않게):

| 위치 | 범위 | 예 |
|---|---|---|
| `작업폴더/CLAUDE.md` | 그 폴더에서만 | 프로젝트 목적, 폴더 규칙, 산출물 형식 |
| `~/.claude/CLAUDE.md` | 모든 작업(전역) | "항상 한국어로", "바꾸기 전에 먼저 설명해줘" |

- 직접 쓰지 말고 **`/init`** 으로 초안(이미 있으면 개선안)을 받아 검수.
- CLAUDE.md 뼈대 5가지: **작업 개요 · 도구/환경 · 작업 규칙 · 금지 사항 · 자주 쓰는 작업**
- 반복 업무는 "자주 쓰는 작업"에 절차로 박제 → **"정산해줘" 세 글자**.
- 진화 계단: 지난번처럼(폴더 흔적) → 지난달처럼(매번 말) → **영원한 규칙(파일)**.
- 잘 정리된 CLAUDE.md는 비용도 줄인다(응답 빠름, 한도 오래감).
- 더 큰 자동화의 문: **스킬**(매뉴얼 문서철) · **플러그인**(남이 만든 능력 장착) · **/loop**(켜둔 동안 주기 반복) · **/goal**(목표 달성까지 자율 수행).

**실습 프롬프트**

```text
① 이 폴더에 CLAUDE.md 파일을 만들고 다음 규칙을 적어줘:
- 대답할 땐 결론부터, 설명은 그다음에
- 원본 파일은 절대 덮어쓰지 말고, 항상 새 파일로 저장하기
- 파일을 만들 땐 이름을 "날짜_제목" 형식으로
```
→ 완전히 껐다 켜고 아무 문서나 요약 시켜서 규칙 확인

**내 문체 가르치기** (내가 직접 쓴 글 2~3편을 `내글/` 폴더에)

```text
② (내 글 읽히기 전) 다음 주 화요일 오후 2시 팀 회의 안내 메일 초안 써줘. 안건은 3분기 실적 점검. 초안_전.md로 저장해줘.
```

```text
③ @내글/ 폴더의 글을 모두 읽고 내 문체 특징을 정리해줘. 항목은 문장 길이, 자주 쓰는 종결 어미, 자주 쓰는 말, 거의 안 쓰는 말. 항목마다 근거가 된 문장을 내 글에서 하나씩 붙여줘.
```

## Chapter 8. 안전하게 쓰기

**핵심**
- **확인창은 안전벨트.** 신뢰는 **폴더 단위**로 쌓는다 (내 실습 폴더는 auto, 회사 공유 폴더는 manual).
  - manual: 새 폴더·처음 하는 일·중요 파일·회사 PC
  - accept edits: 충분히 겪어본 폴더의 반복 작업 (삭제도 안 물을 수 있으니 원본 폴더 X)
  - auto: 내 폴더의 긴 작업 (회사 공유 폴더 비권장)
  - `--dangerously-skip-permissions`는 **영원히 금지**
- **선 세 개**
  1. **남의 개인정보** (고객·직원·환자·학생) → 회사 AI 가이드라인부터 확인
  2. **비밀번호·API 키** → 대화창에 치지 말고 `.env`에 두고 위치만 알려주기
  3. **돈(결제·송금·계약)** → 만들 수는 있어도 혼자 공개 X, 전문가 검토
- 공통 원칙: **AI 직원이 만들고, 사람이 내보낸다.** (발송·제출·공개 버튼은 사람 손에)
- **환각(hallucination)** 대처 3습관: "됐다"는 말 대신 **내 눈으로 확인** / **"진짜 있는 거야? 근거 보여줘"** 되묻기 / **"모르면 모른다고 해"** 미리 일러두기
- **막혔을 때 4단계**: ① 에러를 그대로 던진다 → ② `/clear`로 새 판 / "다른 방법으로 접근해줘" → ③ QR 영상·부록 C → ④ Q&A 채널

**실습 프롬프트**

```text
# 비밀 정보 다루기
비밀 정보는 .env 파일에 정리해두고, 그 파일은 절대 열어서 내용을 보여주거나 어디에 올리지 않게 해줘. .gitignore에도 넣고.
```

```text
# 에러가 나면 (캡처를 @로 던져도 됨)
① 방금 이런 에러가 났어. 왜 그런지 쉬운 말로 설명하고, 고쳐줘.
```

```text
# 환각 줄이기
그거 실제로 있는 거야? 근거를 보여줘
확실하지 않으면 지어내지 말고 모른다고 해줘
```

```text
# 내 상황별 안전 수칙 만들기 → CLAUDE.md 금지 사항에 박기
내 상황은 이런데, 클로드 코드에게 시키면 안 되는 일 목록을 같이 만들어줘
```

## 치트시트 — 명령어·단축키

### 터미널에서

| 명령 | 용도 |
|---|---|
| `claude` | 시작 (로그인) |
| `claude --continue` | 어제 세션 이어서 |
| `claude --version` | 설치 확인 |
| `claude doctor` | 설치 진단 |
| `claude update` | 수동 업데이트 |

### 대화창 안에서

| 명령·키 | 용도 |
|---|---|
| `/clear` | 주제가 바뀌면 대화 초기화 ★ |
| `/compact` | 길어진 대화 압축 |
| `/context` | 대화가 얼마나 찼는지 확인 |
| `/rewind` / 빈 입력칸에서 `Esc` 두 번 | 되감기 메뉴 |
| `/init` | CLAUDE.md 초안/개선안 |
| `/exit` / `Ctrl+C` 두 번 | 종료 |
| `Esc` | 멈추고 끼어들기 |
| `Shift+Tab` | 권한 모드 전환 |
| `Shift+Enter` | 여러 줄 입력 |
| `@` | 파일·폴더 가리키기 (자동완성) |
| `/` | 명령어 목록 자동완성 |

> 슬래시 명령어는 **대화창 안**, `claude`류는 **터미널**에서.
